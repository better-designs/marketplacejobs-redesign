# Marketplace Jobs redesign

A redesign of [Marketplace Jobs](https://marketplacejobs.com), built with the [Better Design](https://better-design.com) MCP. Every page and interaction is here, with a snapshot of the live listings.

## Run it

```bash
bun install
bun run dev
```

Then open http://127.0.0.1:5191.

The AI tools run on a local matcher, so they need no key.

## Built with

Vite, React 19, Tailwind v4, Base UI and the Marigold design system from Better Design, with its colours set to black.
